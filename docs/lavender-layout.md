# 라벤더 카드 레이아웃 정리

## 적용 범위

기존 화면 구조와 기능을 유지하면서 밝은 카드 중심의 레이아웃으로 정리했습니다. 다른 로컬 복제본과 백업은 변경하지 않았습니다.

- 배경은 `#F7F7F9`, 주요 카드는 흰색으로 통일했습니다.
- 카드 모서리, 간격, 테두리와 그림자를 공통 토큰으로 조정했습니다.
- 기존 Orb를 재사용하는 `PageAtmosphere`로 화면 상단에 옅은 라벤더 안개를 배치했습니다. 기존 저속 애니메이션과 모션 감소 설정은 유지했습니다.
- 헤더는 여백을 둔 흰색 내비게이션으로 정리했습니다.
- 로그인, 회원가입, 행사 목록·상세, 입장권, 기기 안내, 학생회 및 운영진 화면에 공통 카드 스타일을 적용했습니다.
- 행사 카드의 기존 학교별 그라데이션에는 얇은 흰색 레이어를 추가했습니다.
- 입장권 QR은 작은 화면에서도 잘리지 않도록 반응형 표시를 보완했습니다.

## 주요 파일

- `apps/web/tailwind.config.js`: 배경, 표면, 모서리, 그림자 및 운영진 화면 색상 토큰
- `apps/web/src/index.css`: 공통 표면과 상단 배경 스타일
- `apps/web/src/components/Orb.tsx`: 기존 Orb를 재사용하는 PageAtmosphere
- `apps/web/src/app/layouts.tsx`, `AdminLayout.tsx`, `OpsLayout.tsx`: 기존 레이아웃에 공통 배경과 간격 적용
- `apps/web/src/components/`: Card, AppHeader, Button, IconButton, TextField, TicketCard 및 운영진 UI
- `apps/web/src/pages/`: 기존 페이지의 간격, 카드와 정렬 조정
- `DESIGN.md`, `CLAUDE.md`: 현재 시각 지침 반영

## 유지한 사항

이번 레이아웃 작업 전후로 아이콘 구현, 패키지 설정, API, 인증, 라우터 등을 포함한 보호 대상 16개 파일의 해시가 동일한지 확인했습니다. Tailwind의 글꼴 관련 설정도 작업 전 백업과 동일합니다. 기존 Nucleo Glass SVG의 도형·매핑·ID 처리와 글꼴 구성을 변경하지 않았습니다.

인증, 회원가입, 백엔드, 데이터 구조와 API 계약은 변경하지 않았습니다. 기기 초기화 요청 전후의 기본 버튼 그라데이션이 동일한 것도 확인했습니다. 새 의존성은 추가하지 않았습니다.

## 확인 내용

로컬 mock 모드에서 실제 브라우저로 확인했습니다.

- 소개 화면: 데스크톱 1440px 및 1024px
- 로그인·회원가입: 모바일 390px 및 작은 화면 320px
- 행사 목록·상세: 모바일 화면
- 입장권: 320px에서 QR 전체 표시와 화면 넘침 여부
- 기기 안내: 초기화 요청 전후 화면과 버튼 색상 일관성
- 운영진 개요: 1440px에서 3열, 1024px에서 2열 배치와 배지 줄바꿈

검사한 화면에서 가로 넘침이 없었습니다. 브라우저 확인 과정에서는 mock 계정만 사용했으며, 기기 초기화 요청도 mock 상태에만 반영했습니다. 실제 메일 발송, 카메라 권한, 운영 서버의 저장·인증은 이번 시각 검사의 범위에 포함하지 않았습니다.

프런트엔드 테스트는 22개 통과, 2개 건너뜀입니다. TypeScript를 포함하는 빌드와 린트 명령이 완료됐습니다. 린트에는 기존 React 관련 경고가 남아 있습니다. `git diff --check`도 통과했습니다.

## 로컬 확인

개발 서버가 실행 중이면 `http://127.0.0.1:5200/` 또는 `/about`에서 확인할 수 있습니다. 직접 시작할 때는 저장소 루트에서 다음 명령을 사용합니다.

```sh
npm --prefix apps/web run dev:mock -- --host 127.0.0.1 --port 5200 --strictPort
```

사용자 요청에 따라 최신 main의 취소 배지 수정 사항을 유지하면서 이 프런트엔드 변경을 main에 반영합니다. 백엔드 변경과 배포 명령 실행은 포함하지 않습니다.
