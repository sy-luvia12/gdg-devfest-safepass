# Open Peeps 군중 스프라이트

- 일러스트: Open Peeps — https://www.openpeeps.com/
- 원본 이미지: https://s3-us-west-2.amazonaws.com/s.cdpn.io/175711/open-peeps-sheet.png
- 사용자 제공 애니메이션: Skiper UI, Skiper 39 Canvas_Landing_004 — https://skiper-ui.com/
- 원본 참고: https://codepen.io/zadvorsky/pen/xxwbBQV

사용자 제공 GSAP 애니메이션의 스프라이트 분할, 이동 경로, 무작위 속도 및 군중 정렬을 유지했습니다. 별도 예제 페이지 래퍼 대신 /about의 전용 무대에 연결했습니다. Canvas 크기, React 해제 처리와 모션 감소·숨김 탭 일시 정지만 보완했습니다. 출처 표시는 /about 하단에도 있습니다.

Saans 파일과 다국어 경로는 현재 저장소에 없어 추가하지 않았습니다. 기존 글꼴을 대체 글꼴로 사용하며 로그인·회원가입·운영진 경로를 유지합니다. GSAP를 프런트엔드 의존성으로 추가했습니다. 이 변경은 /about 랜딩 화면과 필요한 리소스·의존성만 포함합니다. 배포 명령은 실행하지 않았습니다.
